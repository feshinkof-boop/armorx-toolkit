# Code of Conduct

## Our standard

Be respectful, technical, and evidence-driven.

Healthy disagreement about protocol interpretation is welcome. Personal attacks, harassment, spam, and deliberate misinformation are not.

When correcting a protocol claim, focus on reproducible evidence rather than the contributor.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, and other project-managed community spaces.

## Enforcement

Maintainers may edit, hide, lock, or remove contributions that violate these expectations.
