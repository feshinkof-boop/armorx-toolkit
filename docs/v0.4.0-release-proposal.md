Draft `RELEASE_NOTES_v0.4.0.md` (to be created on the release commit):

> **v0.4.0 — Linux BLE configuration writes**
>
> The toolkit can now write a controller configuration from Linux over BLE, using
> the same `D6`/`D7`/`0E` primitives the offline tools describe, behind a guarded
> pipeline: two agreeing live reads, an automatic pre-write backup that is
> reopened and SHA-verified, a decoded byte-level diff, a refusal when a byte no
> recovered field covers would change, operator confirmation, ten `D7` fragments,
> one `0E` persistence frame and two `D6` verifications that must both match the
> target. `armorx live rollback` writes back the exact bytes of a saved backup.
> Both commands were validated end-to-end against real hardware on 2026-09-29,
> including a physical effect check and power-cycle persistence, with the device
> restored byte-for-byte to its original configuration. Linux only; the Windows
> application is a separate deliverable. Requires Python 3.10+ and
> `pip install "armorx-toolkit[live]"`.

Draft `CHANGELOG.md` entry:

```markdown
## [0.4.0] - unreleased

### Added
- `armorx live apply TARGET --address ADDRESS`: guarded configuration write with
  automatic backup, decoded diff, unknown-byte refusal, operator confirmation,
  `D7` + one `0E` + two `D6` verifications.
- `armorx live rollback PREFIX --address ADDRESS`: writes back the exact saved
  backup bytes, refusing unless the backup files agree and the live image is that
  backup or the target recorded by the apply that preceded it.
- `armorx.diff`: reusable byte- and field-level configuration diff.
- `armorx.confirm`: kdialog / terminal / explicit-automation confirmation.
- scan output now explains its conservative classification with `candidate_reason`.

### Fixed
- `apply` now records the session record before writing, so the normal
  apply-then-rollback pair works without `--allow-unrelated-state`.
- verification attempts are labelled by what the image is (`BASELINE` / `TARGET` /
  `UNEXPECTED`), not by what the caller expected.
```
