# v0.4.0 release readiness review

Status: **released as v0.4.0 on 2026-09-29**.

This review supersedes the earlier proposal. The previously listed ordering
blocker is closed: PR #8 was merged and v0.3.0 was published on 2026-09-29 before
this release candidate.

## Blocking

**None currently identified.**

PR #9 was merged into `main`, final release CI passed, and tag `v0.4.0` points
to merge commit `0c6225ad9a4731895203ed3e57f838f7f61126a2`. The GitHub release publishes
the wheel, sdist, source ZIP and SHA-256 checksum manifest.

## Non-blocking / deliberately bounded

- `--yes --acknowledge-backup` is unit-tested; the supervised hardware
  validation used the interactive KDE path.
- `--allow-unknown-diff` remains deliberately unexercised on hardware; unknown
  changes are refused by default.
- Mid-write connection loss is failure-injected in hardware-free tests, not on
  a real device; behavior is no blind retry, read-only classification.
- Adapters that hide the local name remain conservatively unclassified rather
  than guessed.
- Unknown/reserved configuration semantics remain unknown.
- The Windows GUI is a separate v0.2.1 deliverable.
- The two `validate-*` commands ship as explicitly experimental validation
  tools for reproducibility.
