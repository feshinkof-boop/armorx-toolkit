# Security Policy

ArmorX Toolkit is a research and interoperability project for user-owned controller hardware.

## Please do not publish

- access tokens or credentials;
- personal device identifiers;
- account identifiers;
- private configuration records;
- traffic captures containing unrelated personal data;
- proprietary application binaries.

## Reporting a security issue

If you discover a vulnerability in the toolkit itself, please avoid posting exploit details in a public issue before a fix is available.

For protocol research, keep testing non-destructive and limited to hardware, accounts, and configuration data you are authorized to use.
